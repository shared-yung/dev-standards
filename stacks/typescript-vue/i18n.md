# TypeScript + Vue: i18n（I18N の実装）

- vue-i18n を使う。文言はハードコードしない（I18N-01）。強制は `no-raw-text`
- ロケールは TypeScript で書く（`ja.ts` を `as const` で書き、型を導出する）。他ロケールのキー不足と、存在しないキーがコンパイルエラーになる。失うのは未使用キーの検出（`@intlify/eslint-plugin-vue-i18n` の `no-unused-keys` は `.ts` 非対応）。根拠は `rationale/` を参照
- キーの共有・命名・文の組み立ては I18N-02〜04 のとおり
