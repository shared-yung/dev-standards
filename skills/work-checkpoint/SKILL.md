# 作業の区切り

判断基準は1つだけ。

> **このセッションを見ていない自分が、次の作業を始められるか。**

始められるなら、コンテキストをこれ以上積む価値は下がっている。始められないなら、足りないのは会話ではなく**ファイルに書かれていない何か**で、それを書くのが次の仕事。

セッションに溜めた文脈は消える。ファイルに書いた文脈は残る。**区切りとは、後者が前者を上回った瞬間**のこと。

## 区切りのサイン

2つ以上当てはまったら提案してよい。

- **一連のテーマが終わった。** 積み上げてきた issue 群が閉じ、次は別の塊に入る。マイルストーンの完了はほぼ確実に区切り
- **次の作業が、今の文脈をほとんど使わない。** feature・層・関心事が変わる
- **このセッションで決めたことが、すべてファイルか issue に載っている**
- **残っているコンテキストの大半が探索の残骸。** 読んだだけのファイル、通らなかった試行、確認済みの出力
- **会話が要約された。** 要約された時点で忠実さは既に失われている。区切りを疑う

### 区切りとして扱わないもの

**粒度を上げる。細かく提案すると、提案そのものがノイズになる。**

- **PR 1本の完了やマージ。** PR 本文の「計画との差異」と、フック / CI が外部化を既に強制している。**仕組みで担保されているものを判断軸にしない**
- コミットが積まれたこと、テストが通ったこと、issue が1つ閉じたこと

これらは区切りの**必要条件**であって、きっかけではない。

## 区切ってはいけないとき

1つでも当てはまったら**提案しない**。先にこれを解消する。

- 未コミットの変更がある
- 決めたのに記録していないことがある（ADR / spec / issue コメントが未更新）
- 次の作業が、このセッションでしか分からない暗黙の前提に依存している
- 検証が途中（テストが赤いまま、CI の結果待ち）

## 外部化チェックリスト

区切る前に、**セッションにしか無い情報をゼロにする**。

| 何を                 | どこへ                                              |
| -------------------- | --------------------------------------------------- |
| 動くコード           | コミット。作業ツリーに残さない                      |
| 計画とのズレ         | PR 本文の「計画との差異」                           |
| 決定と、その根拠     | ADR。仕様が動いたなら spec も                       |
| 決めきらなかったこと | issue（既存へのコメント、または新規）               |
| 次の一手             | 次の issue 番号。無いなら issue を立てる            |
| 試して駄目だった案   | 選択肢として ADR に。**同じ検討を繰り返さないため** |

**「後で説明すればいい」は外部化ではない。** 説明する自分が居なくなるのが区切りの前提。

## 引き継ぎ文の雛形

区切ると決めたら、次のセッションの1通目をこちらから出す。

```
<リポジトリの絶対パス> で <何> を開発中。
<直前のマイルストーン> 完了、<現在のマイルストーン> の途中。次は issue #N。
規約は CLAUDE.md と docs/ に、<固有の仕様> は <パス> にある。
未決: <あれば1行。無ければ書かない>
issue #N から進めて。
```

- パスは絶対。issue は番号で
- **セッション内でしか意味を持たない言葉を使わない。**「さっきの」「例のファイル」「今の方針」
- **5行を超えたら、それは外部化が済んでいない証拠。** 溢れた分をファイルへ移してから書き直す

## 計画段階での使い方

区切りは事後に気づくものではなく、**計画に織り込むもの**。

- 計画には**「ここで区切る」候補を明示する。** 単位はマイルストーンかテーマ。**PR ごとには置かない**
- 各候補に「その時点で何がファイルに残っているか」を1行添える
- **計画が2つ以上のテーマにまたがるなら、最初の区切りまでを計画とし、残りは issue に落とす。** それ以上先は、実装で前提が変わるので計画の精度が出ない

## 提案のしかた

- **1行で言い、作業は止めない。** 例:「M2 のドメインは #16 まで閉じました。ここで区切ると、次は M3 の通信を #17 から始められます」
- 提案の前に、外部化チェックリストを**自分で通しておく**。「区切りましょうか」だけ言って未コミットが残っているのは最悪
- **断られたら、そのセッションでは二度と言わない。** 蒸し返さない
